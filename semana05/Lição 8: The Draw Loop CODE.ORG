# Avaliação

```javascript
World.frameRate = 10;
var salt = createSprite(200,200);
salt.setAnimation("salt");
salt.rotation = 180;

function draw() {
  salt.y = randomNumber(200, 210);
  background("skyblue");
  drawSprites();
}
// O programa cria um sprite de sal e define sua rotação. A posição vertical do sal é alterada aleatoriamente entre 200 e 210 a cada execução do draw, criando um pequeno movimento. A taxa de atualização foi definida em 10 frames por segundo.

menina.setAnimation("menina");

  drawSprites();
